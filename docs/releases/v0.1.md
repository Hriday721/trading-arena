# v0.1: order book engine (Week 1)

The core market engine for Trading Arena: a tested, replayable order book in TypeScript.

## What's in it

- **Order types:** limit, market and stop (stop-market behaviour), plus cancel and modify.
- **Matching:** price-time priority, partial fills, multi-level sweeps, trades at the resting order's price, with sequence numbers and aggressor side.
- **Hidden stops with cascades:** stops live outside the visible book and fire on last traded price, one after another.
- **Depth snapshot:** price ladder with quantity, order count and running totals, plus last price, spread and mid price.
- **Price levels:** one queue per price level, binary-search inserts and lookup by order id, so large books stay fast.
- **Validation:** tick size, lot size, quantity and price checks, and duplicate ids. `place()` and `modify()` return `{ ok: false, reason, message }` instead of throwing.
- **Modify rules:** cutting size keeps queue position; raising size or changing price goes to the back and can trade straight away.
- **Event log and replay:** `recording()` and `OrderBook.replay(recording, untilEventId)` rebuild the exact book, with `tape()` and `stopOrders()` for the audit view.

## Quick example

```ts
import { OrderBook } from "@arena/engine";

const book = new OrderBook({ tickSize: 5 });
book.place({
  id: "s1",
  traderId: "t1",
  side: "sell",
  type: "limit",
  price: 10000,
  quantity: 10,
  timestamp: 1,
});
const result = book.place({
  id: "b1",
  traderId: "t2",
  side: "buy",
  type: "limit",
  price: 10000,
  quantity: 4,
  timestamp: 2,
});

if (result.ok) console.log(result.trades);
console.log(book.depth());

const copy = OrderBook.replay(book.recording());
```

Prices are whole paise (₹100.00 is 10000).

## Tests

65 tests in 6 files: matching (8), market/cancel/stop (11), depth and mid price (13), benchmark (1), validation and modify (20), event log and replay (12).

## Known limits

- `submit()` skips validation; use `place()` for player input.
- `modify()` handles resting limit orders only.
- Rejected orders are not logged; replay starts from an empty book.
- Self-trades are not prevented yet.
- Order ids can be reused once an order has left the book.
- There is no clock or scenario layer yet (Week 2).
